# DETROID — Automotive 3D Showroom

Showroom digital independente para descoberta de carros e motos. A primeira coleção será focada em veículos Mitsubishi, com arquitetura preparada para adicionar outras marcas.

## Status

**Fase 1 — Fundação visual:** landing page responsiva e conceito inicial do catálogo.

**Próximas etapas**
- [ ] Confirmar imagens e direitos de uso dos ativos visuais.
- [ ] Criar páginas de detalhes para cada veículo.
- [ ] Integrar um modelo 3D real em GLB/glTF usando Three.js / React Three Fiber.
- [ ] Adicionar filtros e dados de catálogo tipados.
- [ ] Integrar contato comercial (por exemplo, WhatsApp).
- [ ] Testar acessibilidade, desempenho e visualização em dispositivos móveis.

## Tecnologias

- Next.js App Router
- React + TypeScript
- CSS responsivo
- Three.js / React Three Fiber (etapa futura)

## Executar localmente

Requer Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Observação sobre marcas e anúncios

DETROID é um projeto independente e não representa a Mitsubishi Motors. Nomes de modelos e marcas pertencem aos seus respectivos titulares. Antes de publicar anúncios comerciais, confirme disponibilidade, especificações, imagens e permissões de uso.
