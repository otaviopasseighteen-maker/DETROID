# DETROID — Automotive 3D Showroom

Showroom digital independente para descoberta de carros e motos. A primeira coleção é focada em veículos Mitsubishi, com arquitetura preparada para adicionar outras marcas.

## Status

**Fundação visual + seletor 3D Mitsubishi:** a experiência 3D incorpora modelos públicos do Sketchfab em um iframe e permite alternar entre três veículos. Os arquivos 3D continuam hospedados pelo Sketchfab; não são redistribuídos neste repositório.

### Modelos 3D e atribuição

- **2015 Mitsubishi Lancer Evolution Final Edition** — modelo de Ddiaz Design. [Fonte e modelo 3D](https://sketchfab.com/3d-models/2015-mitsubishi-lancer-evolution-final-edition-a31a821037c94684bbbd3312cd4d5896). Licença indicada na página: **CC BY-NC-SA**.
- **1999 Mitsubishi Eclipse GSX** — modelo de Ddiaz Design. [Fonte e modelo 3D](https://sketchfab.com/3d-models/1999-mitsubishi-eclipse-gsx-38ea726a6aae496981069cdfdb140adc). Licença indicada na página: **CC BY-NC-SA**.
- **1998 Mitsubishi 3000GT VR-4 Turbo** — modelo de SIU Car Garage. [Fonte e modelo 3D](https://sketchfab.com/3d-models/1998-mitsubishi-3000gt-vr-4-turbo-3e7ffda18a274ce4a5453a2c2591d2ac). Licença indicada na página: **CC BY-NC**.

**Importante sobre licenças:** as três licenças listadas restringem uso comercial. Mantenha a experiência apenas em contexto não comercial enquanto esses modelos forem usados. Antes de monetizar o DETROID, confirme os termos atuais nas páginas originais e substitua os modelos por ativos com autorização comercial apropriada, se necessário. A atribuição do criador e a licença são exibidas junto ao visualizador.

## Tecnologias

- Next.js App Router
- React + TypeScript
- CSS responsivo
- Sketchfab Embed para a primeira coleção de modelos 3D

## Executar localmente

Requer Node.js 20.9 ou superior.

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Observação sobre marcas e anúncios

DETROID é um projeto independente e não representa a Mitsubishi Motors. Nomes de modelos e marcas pertencem aos seus respectivos titulares. Confirme disponibilidade, especificações, imagens e permissões de uso antes de publicar anúncios comerciais.
